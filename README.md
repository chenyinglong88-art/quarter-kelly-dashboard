# Quarter Kelly 稳健执行版仪表板

这是一个静态、只读的足球1X2历史回测仪表板，展示 **B版滚动xG泊松低赔率1X2策略** 在五大联赛中的历史资金曲线、回撤、仓位、联赛贡献及417笔逐笔记录。

## 在线网站

<https://chenyinglong88-art.github.io/quarter-kelly-dashboard/>

## 冻结策略

| 参数 | 规则 |
|---|---|
| Kelly倍数 | 0.25× |
| 单笔硬上限 | 日初资金的2% |
| 单日硬上限 | 日初资金的6% |
| 联赛权重 | 西甲1.30×；英超、法甲、意甲、德甲1.00× |
| 回撤降仓 | 回撤<6%使用100%；6%—9%使用80%；≥9%使用60% |
| 执行价格 | 每笔必须按实际可成交赔率重算，Kelly非正或EV不足则跳过 |

## 网站功能

网站支持全区间、开发期、留出期和近12个月筛选，可切换资金、回撤、日盈亏和仓位视图，并可按联赛与红黑结果筛选逐笔记录、导出CSV。

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
```

## 数据与限制

网站内嵌的是2022-01-02至2026-08-22的历史回测数据。所有结果均为历史模拟，不代表未来收益；最大历史回撤不是未来损失上限。该网站不连接任何博彩账户，不接受资金，不自动提交下注。

## 技术栈

React、TypeScript、Vite、Recharts。GitHub Actions自动构建并发布到GitHub Pages。
